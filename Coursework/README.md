# EstateCRM

Учебный курсовой проект — информационная система для агентства недвижимости.

Система предназначена для просмотра объектов недвижимости, подбора объектов
по заявкам клиентов, учёта просмотров и оформления сделок.

## Возможности

- Просмотр каталога объектов, поиск, фильтрация и сортировка.
- Подбор объектов по существующей заявке клиента.
- Назначение просмотра, отметка о его проведении и отмена.
- Просмотр и оформление сделок с расчётом комиссии.
- Просмотр сводки по сделкам за выбранный период.
- Разграничение действий по ролям сотрудников.

## Роли пользователей

- **Риелтор** — работа с каталогом, заявками, просмотрами и сделками.
- **Руководитель** — работа с каталогом, просмотрами и сделками;
  просмотр сводки по сделкам.
- **Администратор** — работа с каталогом, просмотрами и сделками;
  просмотр сводки и изменение даты сделки.

Все три роли могут назначать и отменять просмотры,
а также отмечать их проведёнными.

## Используемые технологии

- C# и .NET 10;
- Avalonia UI 12.1.3;
- Entity Framework Core 10.0.12;
- Microsoft SQL Server;
- SQL Server Management Studio.

## Состав проекта

- `src/EstateCRM.app` — исходный код приложения.
- `database/EstateCRM.sql` — скрипт базы данных.
- `docs` — пояснительная записка, диаграммы и протокол тестирования.
- `resources` — сведения об источниках графических ресурсов.
- `tests` — дополнительные материалы тестирования.

## Подготовка базы данных

1. Откройте SQL Server Management Studio и подключитесь к своему экземпляру
   SQL Server.
2. Откройте скрипт `database/EstateCRM.sql`.
3. Проверьте, создаёт ли скрипт базу данных самостоятельно. Если нет,
   создайте пустую базу и выберите её перед выполнением скрипта.
4. Выполните скрипт для создания таблиц и заполнения учебными данными.

## Настройка подключения

В папке `src/EstateCRM.app` создайте файл `connection.txt`
или измените существующий. Укажите в нём строку подключения к своей базе.

Пример для локального SQL Server с проверкой подлинности Windows:

```text
Server=localhost\SQLEXPRESS02;Database=EstateCRM;Trusted_Connection=True;TrustServerCertificate=True;Connect Timeout=15
```

Имя сервера и базы данных необходимо заменить, если на компьютере они другие.
Файл `connection.txt` содержит локальные настройки и не загружается в репозиторий.

## Запуск программы

1. Установите .NET 10 SDK.
2. Откройте `src/EstateCRM.app/EstateCRM.App.slnx` в Visual Studio.
3. Восстановите пакеты, если Visual Studio предложит это сделать.
4. Соберите и запустите проект.

Для входа используйте учебные учётные записи, добавленные в базу данных.

## Ограничения

Проект является учебным. Права доступа проверяются приложением;
для реальной эксплуатации необходима отдельная настройка прав SQL Server
и дополнительные меры защиты.

Сводка по сделкам отображается на экране. Экспорт и печать не реализованы.
